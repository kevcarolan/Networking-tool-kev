# Customer documentation

For the people who install, run and use the platform at a customer site. Written for
network engineers. The detailed reference documents in the `docs/` folder are linked
where they go deeper.

| Guide | For | Covers |
|---|---|---|
| [Install guide](install-guide.md) | Whoever builds the server | What you need, choosing the online or air-gapped install, the first visit, the checklist before go-live |
| [Admin guide](admin-guide.md) | Admins | Setup screen, Settings (licence, site and defaults, Active Directory, certificate), users and permissions, devices and credentials, live upgrades, monitoring, backups of the server, upgrading the platform, troubleshooting |
| [User guide](user-guide.md) | Everyone who signs in | Signing in, config backups, firmware versions and images, upgrade jobs, circuits, notices you may see |

The product name is not final yet. These guides call it "the platform", and the server
shows whatever name it is set to.

Reference documents:
* [install-online.md](../install-online.md) and [install-airgap.md](../install-airgap.md):
  step-by-step installs.
* [security-hardening.md](../security-hardening.md): hardening the server.
* [users.md](../users.md): permissions in full.
* [upgrades.md](../upgrades.md): upgrade jobs in full, per platform.
* [upgrade-lab-tests.md](../upgrade-lab-tests.md): the lab sign-off before live upgrades.
* [circuits.md](../circuits.md): the circuit list and live locations.
* [vendors.md](../vendors.md): what each platform supports and the account it needs.
