Everything it does, tool by tool

Each tool works on its own and shares one device inventory, one login and one activity log with the others.

Config backups and compliance

Backups you can rely on, and the reason when one fails

  • Scheduled SSH backups per device, daily or more often
  • Every version kept, with side-by-side differences
  • Compliance rules for the lines a config must have, or must never have, checked after every backup and exported to Excel for an audit
  • An email when a config changes, naming who changed it from the device's syslog
  • Secret-looking lines are never shown in emails or on screens without permission
  • Each device's SSH host key is recorded on first use and checked every time after

Syslog

One place for every device's log messages

  • A receiver on port 514 (UDP and TCP), one file per day, kept as long as you choose
  • Search by text or message code such as %LINEPROTO, or watch messages arrive live
  • The setup commands for each platform, ready to paste

Monitoring

Up and down, traffic and hardware health

  • Ping and SNMP (v2c or v3) every 30 seconds, read-only
  • Interfaces and traffic history, busiest ports, link load on the network map
  • Power supplies, fans, temperature, Cisco stacks, ASA, FortiGate and Palo Alto HA pairs, optic light levels, PoE
  • Your own sensors from any OID, with thresholds and graphs
  • UPS cards, PDUs and room probes as devices of their own
  • Cisco Meraki organisations through the read-only Dashboard API (optional; the one internet connection the product can make)

Firmware and upgrades

A version report, and upgrades you can check before they run

  • Versions, models and serial numbers read from every device, against the standards you set
  • An image library; images are sent from the server, devices never fetch them
  • Upgrade jobs need an admin, a maintenance window and passing pre-checks, and you type the device's name to start one
  • A dry run follows exactly the same steps as the real upgrade
  • Stacks, vPC, ASA failover pairs and Firepower HA, each in the right order

Inventory, sites and racks

Every switch, server, UPS and patch panel, and where it sits

  • One inventory with your own columns; import and export to Excel
  • Sites, buildings, floors and rooms
  • Rack elevations, front, rear and zero-U; drag to move, with overlap checks
  • Circuits: find where each CCTV camera, door controller or access point is plugged in, from the switches' MAC and ARP tables

Wall display and reports

A screen for the NOC, a report for the manager

  • A wall display on its own port with its own key; it shows names and statuses, never configs or addresses
  • A report of backups, compliance, firmware and monitoring, emailed on the day and time you choose
  • A shared calendar of maintenance windows, exported to Outlook
