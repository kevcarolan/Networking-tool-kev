How it works

From email to first backup

  1. Ask for the download

    Email us with your name, your organisation and roughly how many network devices you have. We reply with a download link for the install bundle and its SHA-256 checksum.

  2. Make a small Ubuntu server

    A virtual machine running Ubuntu 26.04: 2 vCPU, 4 GB of memory, a 30 GB system disk and a 100 GB data disk for firmware images. It needs no internet access.

  3. Install from the bundle

    Check the checksum, unpack the bundle and run the installer. It sets up the web server, the certificate and the firewall, and prints a one-time setup code.

  4. Sign in and add your devices

    The setup page creates the first admin and connects Active Directory if you use it. Add devices by hand or import a spreadsheet, and the first backups run straight away.
